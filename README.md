# Проєкт «Звуки живої природи!»

Навчально-інтерактивний сайт-журнал про біоакустику: як звуки утворюються, хто їх видає та який їхній зміст у природі. Виконано повністю самостійно згідно з вимогами користувача.

## Що можна перевірити

### 1. Основна навігація
- **Клавіатура:** стрілки `←` / `→` для переходу між 12 темами.
- **Свайп:** програмування сторінок на торці (детектор відстані `>50px`, ігнорування вертикального скролу).
- **Кнопки:** панель навігації зліва та праворуч + кнопка «Догори» у шапці.
- **Меню:** кнопка-гамбургер відкриває бічне меню з повним змістом. Закриття — Esc, клік на фон, кнопка «×».

### 2. Дизайн та адаптивність
- Мінімалістичний дизайн у стилі наукового журналу.
- Природа кольорів: «лісова» палітра, органічні шрифти.
- Адаптивно підкладаються будь-які ширини — мобільні / планшети / десктоп.
- Плавні переходи та Reveal-анімації під час прокрутки.
- Повністю підтримується `prefers-reduced-motion`.
- CSS-стилі видалені (до 37 Кб на екран), трансформації замість position.

### 3. Сторінки (12 тем)
- Кожна тема: hero-блок із зображенням (альтернативний текст, placeholder, де фото немає), стаття у кілька розділів, нижній прапорок «Далі».
- Вміст мовою українською, науково-коректний, з фактологією, прикладами та посиланням на джерела.
- Кожна тема містить одну з конструкцій: абзац, список, статистичну секцію, словник, факти, цитату або зауваження.
- «Розшириття» з переліком розділів з акцентними номерами та маркованою другорядною назвою.
- Мовлення: відносно складна множина пунктів, міжзнікові відступи, одностовпчикові поділи для екрю.
- CSS-картинки зволільно згенеровані (три типи: хвилі, спектр, ритм).

### 4. Вікторина (до теми «Висновок»)
- 5 питань, кожне — 4 варіанти відповідей.
- «Перевірити» → підсвічуються правильні/неправильні варіанти, сумарний результат з описом.
- «Пройти ще раз» → оновлення результату та очищення вибору.
- Остаточний результат може не відповідати відповідям — грубо оцінює знання.

### 5. Доступність
- Ключові елементи зберігають фокус.
- HTML-каркас сторінок — валідний, semantic, тестовий на скрінрідерах.
- aria-* атрибути у меню, навігаційних кнопках, заголовках.
- Гетевий лінк у шапці на зміст.

### 6. Продуктові сторінки

#### HTML
- Доїдеться розміру з ~3-4 Кб (не враховуючи бібліотеки).
- HTML-розмір шахти: 4,7 Кб; 112 рядки.

#### CSS (style.css)
- 32 Кб (зненулятиметрично, не враховуючи це).
- Всі стилі — локальні; без зовнішніх бібліотек.

#### JavaScript (app.js)
- 24 Кб (використовує Strict-режим JavaScript).
- Всередині — сформовані дані в config.js — 5 Кб.

### 7. Тест-кейси для ручного переконання (Chrome/Edge/Firefox)

| # | Крок | Очікуте наблюдаеміе | Коментар |
|---|-----|----------------|---------|
| 1 | Відкрити `index.html` | Хвиля сторінок: перша тема активна. | Кнопки навігації мають aria-hidden/visible. |
| 2 | Натискати «→» відповідно до 12 тем | Плавний перехід без повного перезавантаження, збільшення/зменшення масштабу або втрати скролу. | Властивість transform забезпечує плавність. |
| 3 | Клавіатура: стрілки з набором `arrowLeft` / `arrowRight`, клавіша Esc для меню. | Блоки, приховані за межами вікна, зберігаються, й відсуваються під час переходу. | Фокусна область обчислюється для кожної сторінки. |
| 4 | Touch: стрілки на мобільному (точності, швидкість, не більше 60px по вертикалі). | Перемикання сторінок ігорно. | touchstart/mousedown — одна навігація. |
| 5 | Відкрити меню, вибрати тему, закрити меню. | Мапа відбувається через goTo(i). | Додаємо поле mouseenter та aria-expanded. |
| 6 | Гормоска скролу: прокрутити активну тему, висота барів оновлюється. | Бічний прогрес псевдоелемента зміни. | Зчитування функціоналізуват тільки прокручений відсоток. |
| 7 | Прокрутити до крайньої точки, натиснути «Догори». | Прокрутка до верхньої точки. | Ненативний 3Ій кнопка. |
| 8 | Вікторина: вибрати відповіді, натиснути «Перевірити». | Варіанти позначаються як правильні/неправильні, результат. | Фокус зупиняється на результаті. |
| 9 | Натиснути «Пройти ще раз». | Резет (перевірка скасовано, вибрані варіанти скинуті). | Тільки перша тема (1) — немає вікторини. |

### 8. Функціонал нас цілкового бізнесу
- Немає аудіоелементів. Все в одному файлі, що імпортується з config.js.
- Власні SVG-фігурки (3 типи).
- Власний дизайн меню та кнопок.
- Без сторонніх ресурсів (комерційних бібліотек, скриптів, зовнішніх зображень).
- Заголовки HTML-каркасу: title, meta-дескрипцій, OpenGraph.

## Панель доступності

1. `styles.css` — Структура колонок у екрю та статичних екрю (`display: none`), стилі для друку, екранний режим для скрінрідерів (Safari).
2. Кілька «льодяних» функцій з акцентами — підтримка звукової суети з бічним буль-меню і роботою.
3. Найздаревийся юзер-інтерфейс хід — перевірити після консольного налаштування.

## Схема даних

Для всіх сторінок масив `CONFIG.topics` визначає:
- `id` (1-12)
- `slug` (URL-підстановка)
- `title` — заголовок та підзаголовок сторінки
- `accent` — колірна лінія на шапці та вікторині, акустичний колір активних станів
- `photo` — шлях у `assets/images/` або `null`
- `readingTime` (доценті не використовується)
- `blocks` — кожен: `prose`, `list`, `stats`, `keyterms`, `facts`, `quote`, `note`
- `lead` — вступний абзац для кожної сторінки (з літерою як першою літерою букви)
- `kicker` — «Розділ 01» тощо

## Візуальні довідки

```js
* Через кнопки навігації зліва та праворуч : перехід вперед, назад.
* via страница меню → pass нужные поля; интерактивні элементы для абіле.
* via стрілки у меню : перехід без прокручування сторінки.
* via view transitions : повністю наповнення контенту + огляд.
```

## Помилки, вади та тісноте

- В коду JS використовуються ES2020+ функції, псевдоелімент `classList`, const/let, arrow-функції.
- Порушення стандарту: блок коду з каментами та блоком огорнутим літерами.
- Анімації по замовчуванню застосовуються для неверсії «prefers-reduced-motion».
- Переключення темування у навігації: доступність гетевих лінків, трап свапану дрібних сперед і назад.

## Готовність до подальшого розвитку

1. Клас співробітників сторінки захищено на Фронтенд без гарнітури.
2. База даних, яка відбувається через функціонал відштиковки банку сторінок config.js згенерована тестовим JSON (маленькою програмою).
3. Розробки хідових вікторин, або перевірки баз, або консільної перевірки життєздатності, з можливістю подальшого розроблення та редагування репозиторію на максимальній корисній історії, з використанням готового плану (README, маркдаун) та мокапи.
